# 云端 ASR 引擎（0c-语音识别工具）

把「一览成文」的云端转写能力接进 GPT-SoVITS 自带的 **0c-语音识别工具**，
和本地引擎（达摩 / Fun-ASR-Nano / SenseVoice / Faster Whisper）**并列可选**。

```
0c-语音识别工具 → ASR 模型 下拉
  ├─ 达摩 ASR (中文经典)                    本地
  ├─ SenseVoice (极速, 5语种)               本地
  ├─ Fun-ASR-Nano (31语种+方言)             本地
  ├─ Faster Whisper (多语种)                本地
  ├─ 讯飞听见 (云端·5h/500MB·说话人分离)      ← 新增
  └─ 自定义 POST (云端·MiniMax/DashScope/自建) ← 新增
```

---

## 快速开始

1. 展开 **0c-语音识别工具 → ⚙ 设置（云端 ASR 引擎）**
2. 点 **📥 从一览成文导入** —— 把你已有的讯飞/自定义 POST 凭证直接搬过来
   （**不抄 LLM 和图床的密钥**，只搬 ASR 相关字段）
3. 或者自己填：APPID + SecretKey（讯飞）／ endpoint + API Key（自定义 POST）
4. 点 **💾 保存设置**
5. 回到 0c，在「ASR 模型」下拉里选云端引擎 → **开启语音识别**

> 不想点导入也行：配置会**自动回落**到一览成文的 `config.json`（只读），
> 所以即使一次都没保存过，直接选云端引擎也能跑。
> 一旦你点了「保存设置」，本地配置优先级更高。

## 三个必须知道的格式契约

云端引擎的输出必须和本地引擎**逐字一致**，否则下游会静默丢数据。

### 1. 标注文件格式

`{输出目录}/{输入目录名}.list`，每行：

```
文件路径|说话人|语言|文本
```

`tools/subfix_webui.py`（0d 标注）按 `split("|")` 切成 4 段，
`GPT_SoVITS/prepare_datasets/1-get-text.py` 同样。少一段就整行被跳过。

### 2. 语言 token 必须在白名单内

`1-get-text.py` 只认 `ZH / EN / JA / KO / YUE`（大小写都收）。
讯飞用的是自己的 `cn`，custom_post 可能给 `auto` —— 映射在
`tools/asr/cloud_common.py` 的 `map_lang()` 里做，**映射错整份 .list 会被丢弃**，
而错误只出现在远处的一行警告里。

### 3. 文本里的标记必须洗掉

云端返回的是带标记的行：

```
[00:10] 日常生活呢其实这是我们非常
[00:13] 【说话人1】普及的，我们可以说……
```

这些标记对「看稿」有用，但对**训练语料**是噪声——模型会把它们学走。
`clean_text()` 负责剥掉。

> ⚠ 早期版本的正则写成 `(?:\[\d+:\d+\]|【[^】]+】)+`，**标签之间不允许空格**，
> 于是 `[00:13] 【说话人1】` 只匹配掉时间戳，说话人标签整段留在正文里。
> 契约测试里锁了这条。

## 关于「加速」

| 场景 | 云端 vs 本地 |
|---|---|
| 3 个切片（12s/12s/10s） | custom_post **2.8s** / 讯飞 **7.7s**（3 路并发） |
| 超长音频 | 讯飞单文件 ≤500MB / ≤5 小时，**服务端自己处理，不切段** |
| 短音频 | 本地达摩并不慢，甚至更快（不走网络） |
| 启动成本 | 云端**不用加载模型**，不用下载权重，不占显存 |
| 说话人分离 | 讯飞支持（需账号开通角色分离权限），本地达摩不支持 |

真正的提速来自三处：

1. **按文件并发**（云端引擎）。耗时全在网络等待上，线程池是真并行。
   本地引擎是 GPU 推理，**不能**这么干——并发只会抢显存，所以本地维持串行。
2. **上传前归一化到 16kHz 单声道**。0b 切片保留源采样率，44.1k 立体声直接上传
   体积是 16k 单声道的近 5 倍。归一化后上传体积大降。
3. **不切段**（讯飞）。长音频整段直传，省掉切分/合并与边界静音风险。

并发数在「⚙ 设置」里调（默认 4）。太高会触发云端限流。

## 多说话人为什么不自动拆行

讯飞能返回 `【说话人1】【说话人2】`，看起来可以按说话人拆成多行 `.list`。
**但那样是错的**：一段音频里混着多个人的声音，而每行只对应一个人的文字，
训练时音文对不齐，会污染数据集。

正确做法是用 **0d-语音文本校对标注工具** 按说话人切开音频。
所以本模块只做「一文件一行」，与本地引擎一致。
